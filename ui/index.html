Scheduled tasks

A prompt that runs itself — hourly, daily, or weekly — and drops its answer into your chats. Tasks run while Koinos AI is open, on whichever model you choose, with the same privacy rules as typed chat.

Models

Trusted models, verified by checksum before first use. Chat picks any model that's on this machine; bigger models answer better and download once.

Import your own model
Any GGUF file on this machine. It's verified (hashed) once and used in place — nothing is copied or uploaded.
